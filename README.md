# Agenda Kegiatan UKM

Repository kelompok mata kuliah **Pengembangan Aplikasi Mobile (IF25-22017)**, Teknik Informatika, Institut Teknologi Sumatera.
Dipakai untuk tugas praktikum mingguan (satu folder per pertemuan) dan proyek kelompok.

## Tema proyek

**Tema 9: Agenda kegiatan UKM** (fitur platform: Notifikasi)

Aplikasi Kotlin Multiplatform untuk melihat agenda kegiatan UKM di kampus dan mengingatkan pengguna lewat notifikasi.
Nomor tema dihitung dari NIM ketua: 48 mod 20 = 8, ditambah 1 = 9.
